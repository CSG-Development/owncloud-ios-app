# Personal Cloud Files

iOS client forked from the ownCloud iOS app.

## Build

Open `ownCloud.xcodeproj` and run the **ownCloud** scheme. Use the Xcode version in `.xcode-version`. Check out the `ios-sdk` submodule before building. There is no CocoaPods step.

## Branches

Day-to-day work is a pull request into `development`. Releases are cut from `master`.

This fork has moved ahead of upstream ownCloud. Do not merge upstream. Cherry-pick the commit you need, or copy the specific values onto a branch from `development`.

## Translations

Strings are not updated through Transifex.
